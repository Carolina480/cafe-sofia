# Café SofIA — Prototipo

Este es el prototipo de tu café, ya convertido en código real:

- `index.html` — la estructura de la página (el "esqueleto").
- `style.css` — todos los estilos (colores, tipografías, tamaños).
- `script.js` — el comportamiento (carrito, pago, animaciones).

## Cómo verlo

Abrí el archivo `index.html` con doble clic: se va a abrir en tu navegador y vas a ver tu café funcionando, igual que en el prototipo de Claude.

## Próximos pasos

1. Instalar **Visual Studio Code** (solo desde `code.visualstudio.com`) y abrir esta carpeta ahí.
2. Instalar **Claude Code** dentro de Visual Studio Code.
3. Una vez instalado, escribir `/guia-cafe-sofia` para seguir construyendo tu café: conectarlo a internet, sumarle el pago real, el panel de administración, y publicarlo para que cualquiera lo pueda visitar.

Este momento — tener tu carpeta de código descargada — es tu **HITO 1** del curso "De un prompt a una app publicada en Internet". ¡Felicitaciones!
